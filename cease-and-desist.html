✅ CEASE AND DESIST CASE CHECKLIST

🔍 Trigger

  • Customer explicitly requests to stop all communication with Affirm and channel of harassment is not specified (e.g., "Do not contact me again").

☎️ Did the customer disconnect after the request?

  • ✅ YES – Customer Disconnected After Request

    • 🖥️ TCN System

    • Stop the calls on TCN by selecting "Never"
    • TCN Disposition: "Cease and Desist"

    • 📂 Salesforce Case Creation

    • Create a Cease and Desist case
    • Fill in Dynamic Fields:
      • User Collections Updated: Disabled: Other
      • Additional Comments: "Cease communication request - [Your Name + First Initial] / [Date]"
      • Status: Closed
      • Close all related cases

    • 👥 Associate Accounts

    • Create a child case for each associate account
    • Repeat the same steps above for each

    • 🛠️ Agent Portal

    • Apply Cease and Desist tool

For any confusion or latest updates, please refer to the official procedure PDF.
